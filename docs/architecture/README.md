# RideLink Architecture Documentation

This section provides comprehensive architectural specifications for the RideLink backend microservices platform, designed in accordance with the IT3130 Application Development specification.

## Documents in this Section

1. [system-context.md](file:///d:/IT3130_AD_Group_Assignment_RideLink/docs/architecture/system-context.md): System context, user roles, external interfaces, and overall deployment topology.
2. [service-boundaries.md](file:///d:/IT3130_AD_Group_Assignment_RideLink/docs/architecture/service-boundaries.md): Detailed responsibilities, domain models, and functional boundaries for each of the 4 microservices.
3. [data-ownership.md](file:///d:/IT3130_AD_Group_Assignment_RideLink/docs/architecture/data-ownership.md): Strict per-service persistence boundaries and prohibition of cross-service database access.
4. [communication-design.md](file:///d:/IT3130_AD_Group_Assignment_RideLink/docs/architecture/communication-design.md): Interservice REST interactions, contracts, and data flow sequences.
5. [security-architecture.md](file:///d:/IT3130_AD_Group_Assignment_RideLink/docs/architecture/security-architecture.md): Role-based access control (RBAC), JWT authentication token flow, and secret management.
6. [technology-compliance.md](file:///d:/IT3130_AD_Group_Assignment_RideLink/docs/architecture/technology-compliance.md): Technology compliance matrix, non-negotiable constraints, and audit evidence.
