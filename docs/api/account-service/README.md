# Account Service API Specification

**Owner:** Fernando B S C (IT24103775)
**Base URL:** http://localhost:8081
**Swagger UI:** http://localhost:8081/swagger-ui/index.html
**OpenAPI Spec:** http://localhost:8081/v3/api-docs

### Planned Endpoints:
- POST /api/v1/auth/register (Passenger/Driver Registration)
- POST /api/v1/auth/login (JWT Token Issuance)
- GET /api/v1/users/{userId} (Profile Query)
- PUT /api/v1/users/{userId} (Profile Update)
- PATCH /api/v1/users/{userId}/status (Account Status Toggle)
